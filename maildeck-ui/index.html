MailDeck

MailDeck は、Gmail や独自ドメインなど複数のメールアカウントを一つの画面で閲覧・送信・整理できる Web メールクライアントです。

主な機能

  • 複数のメールアカウント（IMAP/SMTP、Google アカウント連携）の統合受信箱
  • ルールに基づく自動ラベリングと、ラベルごとの新着通知
  • メールに含まれる認証コード（OTP）の自動抽出

Google アカウントのデータについて

Google アカウントの連携は、ユーザーが連携を選んだ場合のみ行います。Gmail のデータはユーザーにメール機能を提供する目的にのみ使用し、広告や第三者への提供には使用しません。MailDeck による Google API から受け取った情報の利用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。
