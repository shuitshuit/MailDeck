MailDeck プライバシーポリシー

最終更新日: 2026年1月20日

1. はじめに

MailDeck（以下「本サービス」）は、利用者のプライバシーを尊重し、個人情報の保護に最大限の注意を払います。本プライバシーポリシー（以下「本ポリシー」）は、本サービスが利用者の個人情報をどのように収集、使用、保護するかを説明するものです。

2. 収集する情報

2.1 アカウント情報

本サービスでは、AWS Cognitoを通じて以下の情報を収集します。

  • メールアドレス
  • ユーザーID（Cognito Sub）
  • アカウント作成日時
  • 最終ログイン日時

2.2 外部メールアカウント情報

利用者が本サービスに登録する外部IMAPメールアカウントに関する以下の情報を収集します。

  • IMAPサーバーアドレスとポート番号
  • SMTPサーバーアドレスとポート番号
  • メールアドレス
  • ユーザー名
  • パスワード（AWS KMSにより暗号化して保存）
  • SSL/TLS設定
  • 最終メールチェック日時
セキュリティに関する重要な情報： 外部メールアカウントのパスワードは、AWS Key Management Service (KMS) により暗号化された状態でデータベースに保存されます。平文で保存されることはありません。

2.3 利用者が作成するデータ

  • 連絡先情報（名前、メールアドレス、メモ等）
  • 自動ラベリングルール
  • カスタムアクションパターン
  • 検出されたOTPコード（一時的に30分間保持）

2.4 Web Push通知情報

新着メール通知機能を利用する場合、以下の情報を収集します。

  • Web Pushエンドポイント
  • 認証キー（auth）
  • 公開鍵（p256dh）

2.5 ログ情報

本サービスの運用とセキュリティ向上のため、以下のログ情報を収集します。

  • HTTPリクエスト/レスポンス情報（IPアドレス、リクエストURL、ステータスコード）
  • 認証トークン情報（監査目的）
  • パフォーマンスメトリクス
  • エラーログ

これらのログは7日間保持された後、自動的に削除されます。

3. 情報の利用目的

収集した個人情報は、以下の目的で利用します。

  • 本サービスの提供・運営のため
  • 利用者からのお問い合わせに対応するため
  • 本サービスの改善・開発のため
  • 外部IMAPサーバーへの接続認証のため
  • メールの取得・送信のため
  • 新着メールのプッシュ通知を送信するため
  • 不正利用の防止・検出のため
  • 利用規約に違反する行為への対応のため
  • システムの保守・トラブルシューティングのため

4. 情報の保管と保護

4.1 データの保管場所

利用者の個人情報は、以下の場所に保管されます。

  • 認証情報：AWS Cognito（米国西部リージョン）
  • アプリケーションデータ：PostgreSQLデータベース（自宅サーバー）
  • 暗号化キー：AWS KMS（米国西部リージョン）

4.2 セキュリティ対策

本サービスでは、以下のセキュリティ対策を実施しています。

  • 全ての通信はHTTPS/TLSで暗号化
  • 外部メールアカウントのパスワードはAWS KMSで暗号化して保存
  • IMAPおよびSMTP接続は常にSSL/TLS経由
  • JWT（JSON Web Token）による認証
  • Cloudflare Tunnelによる安全な通信経路の確保
  • 定期的なセキュリティログの監視

4.3 データの保持期間

  • アカウント情報：アカウント削除まで
  • 外部メールアカウント情報：利用者が削除するまで
  • 連絡先情報：利用者が削除するまで
  • OTPコード：検出から30分後に自動削除
  • ログファイル：7日間保持後に自動削除

5. 情報の第三者提供

本サービスは、以下の場合を除き、利用者の個人情報を第三者に提供することはありません。

  • 利用者の同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難である場合
  • 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがある場合

6. 第三者サービスの利用

本サービスは、以下の第三者サービスを利用しています。

6.1 AWS Cognito

  • 用途：ユーザー認証
  • 提供元：Amazon Web Services, Inc.
  • プライバシーポリシー：https://aws.amazon.com/privacy/

6.2 AWS KMS

  • 用途：認証情報の暗号化
  • 提供元：Amazon Web Services, Inc.
  • プライバシーポリシー：https://aws.amazon.com/privacy/

6.3 Cloudflare

  • 用途：フロントエンドホスティング（Cloudflare Pages）、ネットワーク接続（Cloudflare Tunnel）
  • 提供元：Cloudflare, Inc.
  • プライバシーポリシー：https://www.cloudflare.com/privacypolicy/

7. 外部メールサーバーへのアクセス

本サービスは、利用者が登録した認証情報を使用して、利用者の外部IMAPおよびSMTPサーバーに接続します。この接続は以下の目的でのみ行われます。

  • メールの取得（受信箱の表示）
  • メールの送信
  • 新着メールの確認（バックグラウンドチェック）

本サービスは、利用者の同意なく外部メールサーバーに保存されているメールを第三者に提供することはありません。

8. Cookie およびローカルストレージ

本サービスは、利用者の認証状態を維持するために、ブラウザのローカルストレージにJWTトークンを保存します。これらの情報は、本サービスの提供に必要な範囲でのみ使用されます。

9. 利用者の権利

利用者は、本サービスに対して以下の権利を有します。

  • 個人情報の開示を請求する権利
  • 個人情報の訂正・追加・削除を請求する権利
  • 個人情報の利用停止を請求する権利
  • アカウントの削除を請求する権利

これらの権利を行使される場合は、本サービスの設定画面から操作いただくか、お問い合わせください。

10. アカウント削除時のデータ取り扱い

利用者がアカウントを削除した場合、以下のデータが削除されます。

  • 利用者のプロファイル情報
  • 登録された外部メールアカウント情報（暗号化されたパスワードを含む）
  • 連絡先情報
  • 自動ラベリングルールおよびカスタムアクションパターン
  • Web Push通知の登録情報

ただし、法令により保存が義務付けられているデータやログについては、所定の期間保持される場合があります。

11. 子どもの個人情報

本サービスは、13歳未満の子どもから意図的に個人情報を収集することはありません。13歳未満の子どもの個人情報を収集したことが判明した場合は、速やかに削除します。

12. プライバシーポリシーの変更

本ポリシーの内容は、法令その他本ポリシーに別段の定めのある事項を除いて、利用者に通知することなく変更することができるものとします。変更後のプライバシーポリシーは、本サービス上に表示した時点から効力を生じるものとします。

13. お問い合わせ

本ポリシーに関するお問い合わせは、本サービス内のお問い合わせフォームまたは設定で指定された連絡先までお願いいたします。

14. 準拠法

本ポリシーの解釈および適用は、日本法に準拠するものとします。
