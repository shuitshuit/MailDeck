# プライバシーポリシー

MailDeck（以下「本サービス」）は、複数のメールアカウントを一つの画面で閲覧・送信・整理できるWebメールクライアントです。運営者（以下「当方」）は、本サービスで取り扱う情報について、以下のとおりプライバシーポリシーを定めます。

最終更新日: 2026年10月6日

## 1. 本サービスの目的

本サービスは、ユーザー自身が登録した外部メールアカウント（Gmail、独自ドメインのIMAP/SMTPサーバー等）に、ユーザーの指示のもとで接続し、メールの閲覧・送信・検索・ラベル付け・新着通知を一つの画面で行うためのサービスです。

## 2. 収集する情報

本サービスでは、以下の情報を取り扱います。

### 2-1. 本サービスのアカウント情報
- メールアドレス、ユーザー識別子（AWS Cognito により管理される認証情報）
- 利用規約・プライバシーポリシーへの同意履歴

### 2-2. 接続するメールアカウントの情報
- メールサーバー設定（ホスト名、ポート、ユーザー名、パスワード）
- Googleアカウント連携時のOAuthトークン（アクセストークン、リフレッシュトークン）と、連携したGmailのメールアドレス
- パスワードおよびOAuthトークンは、AWS KMS（Key Management Service）で暗号化して保存します。

### 2-3. 本サービスの機能に必要な情報
- 連絡先、自動ラベリングのルール、ブロックした送信者、カスタムアクションの設定
- 新着確認のための最終確認位置（メールの識別番号）
- Web Push通知の購読情報
- 認証コード（OTP）の自動抽出機能で検出したコードと、その送信元アドレス・件名（**30分で自動的に失効・削除**されます）
- 自動ラベリング・パターン検出の結果（付与したラベル、検出した値）

### 2-4. ログ
- 障害調査・不正利用防止のため、アクセスログおよびエラーログ（IPアドレス、リクエスト内容、時刻等）を一定期間（7日間）保持します。

## 3. 情報の利用目的

収集した情報は、以下の目的のためにのみ利用します。

- メールの閲覧・送信・検索・フォルダ操作など、ユーザーが求める本サービスの機能の提供
- 新着メールの確認とWeb Push通知
- ユーザーが設定したルールに基づく自動ラベリング、認証コードの抽出
- 障害対応、セキュリティの確保、不正利用の防止
- ユーザーからのお問い合わせへの対応

広告の配信、プロファイリング、ユーザーの情報の販売には一切利用しません。

## 4. Google API の利用について

本サービスは、ユーザーが「Googleでアカウントを追加」を選択した場合に限り、Googleの認可（OAuth 2.0）を通じてGmailに接続します。

### 4-1. 要求するアクセス権限（スコープ）

- `https://mail.google.com/`: GmailのIMAP/SMTPにOAuth 2.0（XOAUTH2）で接続し、メールの閲覧・検索・既読/未読の更新・移動/削除・送信を行うために使用します。GmailのIMAP/SMTPはこのスコープでのみ接続できます。
- `https://www.googleapis.com/auth/userinfo.email`: どのGmailアドレスを連携したかを識別し、重複登録を防ぐために使用します。

### 4-2. Googleユーザーデータの取り扱い

- メールの本文・添付ファイル・件名・宛先などのGmailのデータは、ユーザーが画面で閲覧・操作するとき、新着確認、自動ラベリング、認証コード抽出を行うときに、Gmailから都度取得して処理するものであり、本サービスのデータベースにメール本文を蓄積することはありません。（保存するのは2-3に記載した情報のみです。）
- Googleユーザーデータは、上記の機能をユーザーに提供・改善する目的以外には利用しません。
- Googleユーザーデータを第三者へ販売・提供することはありません。ただし、法令に基づく場合、またはセキュリティ上の理由で必要な場合を除きます。
- 広告（パーソナライズ広告・リターゲティング・興味関心ベースの広告を含む）のために、Googleユーザーデータを利用・転送することはありません。
- 人がGmailのデータを閲覧することはありません。ただし、ユーザーの明示的な同意がある場合、セキュリティ上の目的（不正利用の調査等）で必要な場合、法令を遵守する場合を除きます。
- 一般的なAI/機械学習モデルの開発・学習のために、Googleユーザーデータを利用することはありません。

**MailDeck による Google API から受け取った情報の利用および他のアプリへの転送は、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)（限定的使用の要件を含む）に準拠します。**

*MailDeck's use and transfer to any other app of information received from Google APIs will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.*

### 4-3. 連携の解除とデータの削除

- 設定画面で該当のメールアカウントを削除すると、保存していたOAuthトークンを削除し、Google側のアクセス権も取り消します。
- [Googleアカウントの「サードパーティ製アプリとサービス」](https://myaccount.google.com/permissions)からも、いつでもMailDeckのアクセス権を取り消せます。取り消した場合は、再認証をするまでそのアカウントのメールを取得できません。

## 5. 第三者への提供

当方は、次の場合を除き、ユーザーの情報を第三者に提供しません。

- ユーザーの同意がある場合
- 法令に基づく場合
- 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが困難な場合

## 6. 外部サービスの利用

本サービスは、機能の提供のために以下の外部サービスを利用します。これらのサービスには、各機能の提供に必要な範囲でのみ情報が送信されます。

- Amazon Web Services（AWS Cognito: 認証、AWS KMS: 暗号化）
- Cloudflare（Webサイトの配信および通信の中継）
- ユーザーが接続するメールサービス（Gmail、各IMAP/SMTPサーバー）
- Web Pushの配信サービス（ブラウザ提供元のプッシュサービス）

## 7. 情報の保護

- メールサーバーのパスワードおよびOAuthトークンは AWS KMS で暗号化して保存します。
- 通信はすべて SSL/TLS で保護します。メールサーバーへの接続も SSL/TLS を使用します。
- 他のユーザーのデータにアクセスできないよう、すべての操作で認証済みユーザーを検証します。

## 8. 保存期間と削除

- アカウントおよびメールアカウント設定は、ユーザーが削除するまで保存します。
- ユーザーがメールアカウントを削除したときは、関連する設定・トークン・検出結果を削除します。
- 認証コード（OTP）は30分で削除します。ログは7日間で削除します。
- アカウントの削除やデータの開示・訂正・削除をご希望の場合は、下記の連絡先までご連絡ください。

## 9. Cookie・ローカルストレージの使用

本サービスでは、認証およびセッション管理のために、Cookie およびブラウザのローカルストレージを使用します。広告・行動追跡の目的では使用しません。

## 10. プライバシーポリシーの変更

本ポリシーを変更するときは、本ページで告知します。重要な変更の場合は、サービス内で再度同意をお願いすることがあります。
